TensorZeroの主要機能

LLMゲートウェイ

統一されたAPIで全ての主要なLLMプロバイダーにアクセス。1ms未満のp99レイテンシで高性能を実現。

観測可能性

推論とフィードバックをデータベースに保存し、UIまたはプログラムで分析可能。

最適化

メトリクスと人間のフィードバックを収集して、プロンプト、モデル、推論戦略を最適化。

評価

ヒューリスティクスやLLMジャッジを使用して個々の推論をベンチマーク。

実験

A/Bテスト、ルーティング、フォールバック、リトライなどで自信を持ってデプロイ。

カスタマイズ可能

セルフホスト、GitOps対応、拡張可能なアーキテクチャ。

実際のTensorZeroを使用するには

このデモは、TensorZeroの機能をシミュレートしています。実際のTensorZeroを使用するには：

  1. TensorZero Gatewayをデプロイ
  2. モデルプロバイダーを設定
  3. views.pyのgateway_urlを更新
# 例: TensorZeroクライアントの使用
from tensorzero import TensorZeroGateway

with TensorZeroGateway.build_http(gateway_url="http://localhost:3000") as client:
    response = client.inference(
        model_name="openai::gpt-4o-mini",
        input={
            "messages": [
                {"role": "user", "content": "AIについて俳句を書いてください。"}
            ]
        }
    )
